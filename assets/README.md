# 这里不放美术

本仓库只发代码。宠物包（`pet.json` + `spritesheet.webp`）由使用者放在
`${DSH_HOME:-~/.dsh}/pets/<id>/`，授权由各自作者决定。

仓库的 `.gitignore` 会挡掉 `*.webp`、`*.png`、`*.gif`、`*.jpg`，所以美术文件
**无法被误提交**。`assets/` 目录只保留这份说明。

蓝鲸女仆的素材来自 [`yuxino/dsh-blue-whale-maid`](https://github.com/yuxino/dsh-blue-whale-maid)：
代码 MIT，角色美术与元数据不在 MIT 内，原作者署名 **simashui**
（[codex-pets.net](https://codex-pets.net/#/pets/blue-whale-maid)），仅限个人/学习/非商业使用。
详见该仓库的 `CREDITS.md` 与 `THIRD_PARTY_NOTICES.md`。
